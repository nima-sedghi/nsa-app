# نظرسنجی انتخاب استاد

نظرسنجی زنده‌ی دانشجویی برای انتخاب استاد ترجیحی بین گزینه‌های ارائه‌شده‌ی یک درس. بدون نیاز به لاگین یا تایپ کد — هر مرورگر خودکار شناسایی می‌شه، رای یکتاست، و نتیجه بعد از رای‌دادن (یا با انتخاب "فقط نتیجه رو نشونم بده") نمایش داده می‌شه.

## استک

- **Next.js 15** (App Router) — فرانت‌اند و API روی یه پروژه، دیپلوی‌شده رو Vercel
- **PostgreSQL** با **Drizzle ORM** — [Neon](https://neon.tech) به‌عنوان دیتابیس سرورلس
- **bcrypt + JWT** برای سشن ادمین (کاملاً سمت سرور)
- **Tailwind CSS** — موبایل‌فرست، راست‌به‌چپ

## نکات فنی

- **بدون تایپ کد از سمت کاربر:** هویت هر رای‌دهنده با یه کوکی امن (httpOnly) که تو `middleware.ts` ساخته میشه مشخص می‌شه؛ نیازی به وارد کردن شماره دانشجویی نیست.
- **یکتایی رای در سطح دیتابیس:** `UNIQUE(voter_id, course_id)` رو جدول `votes` — یعنی حتی با دستکاری کلاینت هم نمیشه دوبار رای ثبت کرد؛ رای دوم فقط رای اول رو آپدیت می‌کنه.
- **کنترل دسترسی واقعی:** همه‌ی عملیات نوشتن (ساخت/حذف درس، پاک کردن آرا، ...) از سمت سرور با سشن ادمین چک می‌شن؛ رمز هیچ‌وقت به مرورگر فرستاده نمی‌شه.
- **Rate limiting سطح دیتابیس** برای جلوگیری از رای‌سازی خودکار.
- **ایمپورت هوشمند:** فایل خام خروجی سیستم‌های دانشگاهی (Excel) رو مستقیم می‌گیره، ستون‌های «نام درس» و «استاد» رو خودش پیدا می‌کنه، و موقع آپدیت لیست بین ترم‌ها، تغییرات (استاد جدید/حذف‌شده) رو گزارش می‌ده به‌جای این‌که ساکت رد بشه.

## توسعه‌ی محلی

```bash
npm install
cp .env.example .env   # پرش کن
npm run db:push        # جدول‌ها رو می‌سازه
npm run dev
```

## ساختار پروژه

```
app/
  page.tsx                   صفحه‌ی رای‌گیری (عمومی)
  admin/page.tsx              پنل ادمین
  api/                        endpoint های بک‌اند
lib/
  db/schema.ts                 تعریف جدول‌ها (Drizzle)
  db/index.ts                   اتصال به دیتابیس
  auth.ts                      احراز هویت ادمین (bcrypt + JWT)
  voter.ts                      شناسایی رای‌دهنده از روی کوکی
  rateLimit.ts                  محدودکننده‌ی نرخ درخواست (اتمیک، سطح دیتابیس)
middleware.ts                  صدور کوکی شناسایی برای هر بازدیدکننده‌ی جدید
scripts/
  hash-password.js              ساخت هش bcrypt رمز ادمین
```
