# نظرسنجی انتخاب استاد

نظرسنجی زنده برای دانشجویان تا بین اساتیدی که یه درس رو ارائه می‌دن رای بدن.

## استک

- **Next.js 15** (App Router) — فرانت + API روی یه پروژه
- **Postgres** ([Neon](https://neon.tech), رایگان) با **Drizzle ORM**
- **bcrypt + JWT** برای سشن ادمین (سمت سرور، نه تو کد فرانت)
- **Tailwind CSS** — موبایل‌فرست، راست‌به‌چپ

## چرا امن‌تر از نسخه‌ی artifact قبلیه

| | نسخه‌ی artifact (قبلی) | این نسخه |
|---|---|---|
| رمز ادمین | تو کد جاوااسکریپت فرانت، قابل مشاهده | فقط هش bcrypt‌ش سمت سرور، هیچ‌جا تو فرانت نیست |
| کنترل دسترسی | فقط UI، کسی که کنسول باز کنه رد میشه | همه‌ی نوشتن‌ها از API رد میشن، سشن چک میشه |
| یکتایی رای | تو حافظه‌ی مرورگر، قابل دستکاری | Unique constraint سطح دیتابیس Postgres |
| رقابت همزمان (race condition) | ممکنه رای‌ها همدیگه رو overwrite کنن | هر نوشتن یه تراکنش اتمیک جداست |
| Rate limiting | نداشت | داره (سطح دیتابیس، برای IP) |

## توسعه‌ی محلی

```bash
npm install
cp .env.example .env
npm run db:push
npm run dev
```

## ساختار پروژه

```
app/
  page.tsx              صفحه‌ی رای‌گیری (عمومی)
  admin/page.tsx         پنل ادمین
  api/                   همه‌ی endpoint های بک‌اند
lib/
  db/schema.ts            تعریف جدول‌ها
  db/index.ts              اتصال به دیتابیس
  auth.ts                 احراز هویت ادمین
  rateLimit.ts             محدودکننده‌ی نرخ درخواست
  utils.ts                 توابع مشترک (نرمال‌سازی شماره دانشجویی و...)
scripts/
  hash-password.js         ساخت هش bcrypt رمز ادمین
```
